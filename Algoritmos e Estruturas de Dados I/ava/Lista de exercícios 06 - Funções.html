AED1 - Python

1- Dada uma lista de strings, crie um programa que retorne apenas as que são palíndromos (iguais de frente pra trás).
2- Implemente um programa que recebe uma string e um número N e desloca cada letra do texto N posições no alfabeto (ex: "abc", 2 → "cde"). Se passar do "z", deve voltar para o "a”.
3- Dada uma lista de palavras, agrupe as que são anagramas (mesmas letras em ordem diferente). Exemplo:
Entrada →["amor", "roma", "carro", "roca", "arco"]
Saída →[["amor", "roma"], ["carro"], ["roca", "arco"]]
4- Peça uma senha e verifique se ela é válida segundo as regras:
Pelo menos 8 caracteres
Contém pelo menos uma letra maiúscula, uma minúscula e um número
Não pode ter espaços
5- Dada uma string, compacte-a substituindo sequências repetidas pela letra seguida da quantidade.
Exemplo: "aaabbccccd" → "a3b2c4d1"
6- Faça um sistema de votação. O programa deve:
Pedir votos (número do candidato) em loop até digitar "fim"
Mostrar o candidato vencedor (ou empate) ao final
7- Mantenha duas listas: produtos e quantidades.
O programa deve permitir adicionar produto, remover e vender (diminuindo quantidade).
Se um produto esgotar, deve removê-lo das listas.
8- Implemente uma versão simplificada do jogo da forca:
A palavra secreta é uma string fixa no código
O jogador digita letras em loop
Mostrar a palavra com “_” nos lugares não adivinhados
O jogo termina se a pessoa acertar todas as letras ou errar 6 vezes
9- Dada uma string representando uma expressão matemática com apenas ()[]{}, verifique se os parênteses/colchetes/chaves estão bem balanceados e na ordem correta. Exemplo:
"([{}])" → válido
"([)]" → inválido
"(((()" → inválido
10- Dada uma matriz 9x9 (representada como lista de listas), verifique se é uma solução válida de Sudoku:
Cada linha deve ter os números 1-9 sem repetição
Cada coluna deve ter os números 1-9 sem repetição
Cada bloco 3x3 deve ter os números 1-9 sem repetição
